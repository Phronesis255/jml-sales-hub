Instructions for the brandbook skill

Generate one valid UTF-8 JSON file using the structure below, with schemaVersion: 1. Replace the example values with the client’s brand. Use six-digit hex colors. Write the brand’s voice as a plain-text description, including tone, preferred language and things to avoid. Reference the logo by URL or file path; do not embed the image. Return a downloadable .json file under 1 MB.

{
  "schemaVersion": 1,
  "name": "Northstar Coffee",
  "colors": {
    "primary": "#21405d",
    "secondary": "#f0b442"
  },
  "logo": {
    "path": "assets/northstar-logo.svg",
    "alt": "Northstar Coffee"
  },
  "typography": {
    "heading": "DM Serif Display",
    "body": "Inter"
  },
  "brandVoice": {
    "description": "Warm, curious and practical. Use clear language and specific brewing advice. Avoid jargon and exaggerated claims."
  }
}

What Social OS uses

  • Required: schemaVersion, colors.primary, colors.secondary and brandVoice.description.
  • Colors: primary and secondary theme the account, with contrast adjusted for readability.
  • Brand voice: saved in Client foundation, shown beside creative briefs and included when preparing new prompts. Edit the foundation to refine it; previously saved prompts stay unchanged.
  • Logo and fonts: optional references, saved and displayed in the foundation. They are not loaded or applied yet. A local path does not upload the referenced file.
  • Additional fields: preserved in the imported brand book for future use. They do not alter the workflow.

Workspace backups include the full imported JSON and the foundation’s current voice. Replacing a brand book updates the colors and voice. Existing foundation versions and saved post content remain unchanged.
